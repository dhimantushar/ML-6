# Project 1 - Student Performance Prediction System

## Run in VS Code

Open this folder in VS Code and run:

```bash
pip install -r requirements.txt
python student_performance_prediction.py
```

The project creates a sample dataset using attendance, internal marks,
assignment score, study hours, and previous semester result.

Models:
- Linear Regression
- Random Forest Regression

Metrics:
- MAE
- RMSE
- R2 Score

The program also predicts the final percentage and performance category
for a new student.
